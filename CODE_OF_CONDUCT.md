# Code of Conduct

Archi is a small, source-backed tool built in the open. The expectation for anyone participating — issues, pull requests, discussions, reviews — is simple:

- Be respectful. Disagree about code and approach freely; don't attack people.
- Assume good faith. Most confusing PRs and terse issue reports are time constraints, not malice.
- Keep criticism specific and actionable — "this edge could be a false positive because X" is useful; "this is bad" is not.
- No harassment, discriminatory language, or personal attacks, in any venue connected to this project.

Maintainers may edit, close, or lock issues/PRs/discussions that don't meet this bar, and may block repeat offenders. If something happens that isn't addressed by a maintainer in the open thread, email the address in the repository owner's GitHub profile.

This is intentionally short. If you're unsure whether something crosses a line, it probably does — ask first.
